# Aç kalabalık testi

Her ölçüte 1-5 puan ver ve tek cümleyle gerekçe yaz. Puan gerekçesiz yazılmaz. Birden fazla kitle varsa yan yana sütun aç.

| Ölçüt | Soru | Puan | Gerekçe |
|---|---|---|---|
| **Acı** | Bu bir ihtiyaç mı, “olsa iyi olur” mu? Şu an para, sağlık, ilişki ya da itibar kaybettiriyor mu? | | |
| **Satın alma gücü** | Çözüm için para ödeyebiliyor mu? Benzer bir şeye daha önce para verdi mi? | | |
| **Kolay bulunurluk** | Toplandıkları yerler belli mi? Hafta içinde 50 tanesine ulaşabilir misin? | | |
| **Büyüme** | Bu kitle büyüyor mu, küçülüyor mu, sabit mi? | | |
| **Senin avantajın** (ek) | Bu acıyı kendin yaşadın mı ya da bu kitleyle sonuç aldın mı? | | |

## Okuma

- **Acı ya da satın alma gücü 2 ve altıysa:** Teklif ne kadar iyi olursa olsun zor satar. Kitleyi daralt ya da değiştir.
- **Kolay bulunurluk düşükse:** Önce bir ortaklık ya da topluluk yolu bul; yoksa reklam bütçesi gerekir.
- **Büyüme düşük ama diğerleri yüksekse:** Satılabilir, ama tavanı düşük.
- **Kişisel avantaj yüksekse:** Dilini bildiğin kitle, içerikte en hızlı güveni verir.

Toplam puan bir karar değil, konuşma başlatır. Son sözü kullanıcı söyler.

## Nişi daraltma soruları

Kart çok genişse şu sırayla daralt:
1. **Durum:** “Bütün tasarımcılar” yerine “ilk 2 yılındaki serbest tasarımcı”.
2. **Tetikleyici:** “Fiyat sorunu yaşayan” yerine “bir müşterinin ödemeyi kestiği hafta”.
3. **Sonuç:** “Daha çok kazanmak” yerine “aynı iş sayısıyla iki kat kazanmak”.
